O que mudou

Tudo o que não está listado continua exatamente como no app de hoje — cards, esteira, chat, preview, composer e chips são os componentes atuais.

Quadro — direção B

  • O dropdown de projeto morreu. O quadro nasce em "Todos": uma lista só, agrupada por projeto com cabeçalho fixo no scroll.
  • Chips de filtro no lugar do dropdown: Todos · por projeto (com contagem) · ◆ Sua vez, que atravessa projetos e mostra só o que espera você.
  • Nova tarefa escolhe o projeto ali mesmo ("em: leapy-web ▾") — escreve primeiro, endereça depois. O último projeto usado fica pré-selecionado.
  • Cada grupo tem um "+ tarefa" que abre o composer já endereçado àquele projeto.

Editor — direção C

  • Faixa de abas global sob a barra do app: "Tarefas" é a aba-casa e cada tarefa aberta vira uma aba com selo do projeto.
  • Estado ao vivo na aba: ● pulsando = Claude trabalhando · ◆ âmbar = sua vez (a mesma linguagem dos losangos da esteira) — dá para ver outra tarefa pedir você sem sair de onde está.
  • Trocar de tarefa = 1 clique na aba, inclusive entre projetos. Abrir um card no quadro adiciona a aba; o ✕ fecha (a tarefa continua rodando — a aba é só o seu foco).
  • O "←" de voltar saiu do editor: a aba-casa "Tarefas" está sempre visível no mesmo lugar.

Decisões de implementação sugeridas

Comportamento das abas

  • Abas persistem em localStorage (inhouse.abas) — sobrevivem ao reload, por máquina.
  • Abrir tarefa (por card, link ou URL) adiciona a aba se não existir; concluir/arquivar não fecha sozinho — a aba mostra ✓ e você fecha quando quiser.
  • Limite prático de ~6 abas com ellipsis no título; excedente rola horizontalmente (sem menu extra na v1).

Escopo e fora da v1

  • A faixa aparece em Tarefas + editor; em Início/Experiência/Configurações ela some (nav do topo continua o caminho).
  • "Sua vez" mantém os grupos visíveis (só filtra cards) — o dono da tarefa continua óbvio.
  • Fora da v1: ⌘K (busca global da direção B) e colunas por projeto — ficam anotados como evolução natural.
