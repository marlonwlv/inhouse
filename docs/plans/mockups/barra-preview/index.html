Como funciona: o Inhouse já captura tudo que o app escreve no Registro. Um detector barato (linhas com Error / Unhandled / ⨯ / 500) acende a dot em âmbar, destaca o botão e mostra esta faixa — sem proxy e sem custo de IA. “Consertar” dispara o conserto que já existe, levando a rota junto. “Ignorar” recolhe a faixa (o botão continua âmbar até o próximo start limpo).

O que muda por baixo (resumo para aprovação)

Detector de erro no Registro (novo): o servidor marca a tarefa com “suspeita de erro” quando o dev server escreve linhas de erro fortes, e publica no evento de status que a UI já escuta. Zero IA, zero proxy — acende a dot âmbar, o botão e a faixa. Falso positivo custa um clique em “Ignorar”; falso negativo mantém o botão manual.
Faixa com rota: quando o detector consegue extrair a rota da linha de erro (ou da barra de endereço), ela vai no pedido de conserto e entra nos health-checks futuros.
Sem mudanças no fluxo de conserto em si — só a descoberta fica 10x mais fácil.
